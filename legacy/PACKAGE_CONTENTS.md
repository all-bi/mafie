# Obsah distribučního balíčku

- `index.php` — vstupní stránka aplikace;
- `api.php` — JSON API;
- `src/` — připojení k databázi a herní logika;
- `assets/` — mobilní rozhraní, styly a obrázek;
- `schema.sql` — instalační databázové schéma;
- `config.example.php` — bezpečný vzor konfigurace;
- `.htaccess` — ochrana citlivých souborů na Apache/LiteSpeed;
- `.gitignore` — ochrana lokální konfigurace a artefaktů;
- `README.md` — základní instalace a architektura;
- `docs/PRODUCT_DECISIONS.md` — pravidla a rozhodnutí z návrhu;
- `docs/DEPLOYMENT_WORDPRESS_SUBDOMAIN.md` — nasazení vedle WordPressu;
- `docs/GITHUB_UPLOAD.md` — nahrání na GitHub.

Balíček neobsahuje `.git`, závislosti Node.js, build výstupy, logy ani produkční přístupové údaje.
